## Назначение

Шаблон задаёт минимальный каркас новой пользовательской концепции. В реальной концепции placeholders заменяются содержанием пользователя, а manifest и structure обновляются после каждого изменения.

## Карта концепции

| Файл | Назначение |
|---|---|
| `README.md` | точка входа концепции |
| `about.md` | цель, границы, аудитория |
| `operating_model.md` | роли, состояния, ограничения, процессы |
| `requirements.md` | утверждённые требования |
| `process.md` | подробные процессы |
| `pages/` | дополнительные страницы |
| `Issues/` | concept issue |
| `manifest.jsonl` | машинный список файлов |
| `structure.md` | карта ссылок |
| `state.json` | локальный state концепции |

## Правила

- Новая страница создаётся только через manifest и structure.
- Каждый MD-файл имеет parent link.
- Перед export проверяются ссылки, открытые issue и русский язык.
