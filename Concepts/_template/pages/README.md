## Назначение

`pages/` хранит дополнительные страницы концепции. Новая страница создаётся только если она имеет отдельную функцию, parent link, запись в manifest и путь из точки входа.

## Правила страницы

- Первый заголовок H1 обязателен.
- Вверху нужна ссылка возврата на parent.
- Большие блоки из primary-файлов не копируются.
- Страница должна быть достижима из `README.md`.
