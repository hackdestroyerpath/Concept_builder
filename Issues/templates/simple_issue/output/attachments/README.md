# Attachments результата issue

[← Назад к шаблону report](../report.md)

## Назначение

Папка хранит attachments результата issue, если они прямо нужны contract или report.

## Правила

- Attachment должен быть указан в `report.md`.
- Attachment не должен дублировать рабочий файл без причины.
- Если attachment становится рабочим файлом, он переносится в рабочий путь, а report получает ссылку.
