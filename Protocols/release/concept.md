# Concept release

[Назад к README](../../README.md)

## Назначение

Протокол описывает выпуск готовой концепции.

## Preconditions

Перед выпуском проверить:

- concept state актуален;
- manifest актуален;
- structure актуален;
- blocking issues отсутствуют;
- links проверены;
- release target известен.

## Package

Release package содержит README, manifest, structure, state, pages, output files и нужные attachments.

## Checks

- active files существуют;
- active files указаны в manifest;
- orphan files отсутствуют;
- broken links отсутствуют;
- language gate пройден;
- report сохранён.

## Persistence

Выпуск готов только после записи state, manifest, structure и report через GitHub Connector.
