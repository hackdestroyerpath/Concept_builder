# Input attachments

[← Назад к Inbox](../../README.md)

## Назначение

Папка хранит вложения входного пакета. Вложения являются source material, supporting context или reference, но не становятся точкой входа без явного решения пользователя.

## Правила

- Каждое вложение должно быть описано в `input_manifest.json`.
- Неизвестная роль фиксируется как `unknown`.
- После закрытия связанных issue входной пакет можно очистить только через compact audit trace.
