# Concept Builder

## Назначение

Рабочий репозиторий для ведения концепций через Markdown-файлы, state, registry и протоколы.

## Быстрый старт

1. Открыть этот файл.
2. Открыть [Repository/file_index.jsonl](Repository/file_index.jsonl).
3. Открыть [Repository/link_graph.md](Repository/link_graph.md).
4. Для service-работы открыть [Protocols/service/service_mode.md](Protocols/service/service_mode.md) и [State/service_state.json](State/service_state.json).
5. Для concept-работы открыть [State/execution_index_state.json](State/execution_index_state.json).
6. Для startup открыть [Protocols/common/startup.md](Protocols/common/startup.md).
