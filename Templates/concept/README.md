# Шаблон концепции

[Назад к README](../../README.md)

## Назначение

Шаблон описывает минимальную структуру новой пользовательской концепции.

## Состав

- README.md
- about.md
- operating_model.md
- requirements.md
- process.md
- pages/
- Issues/registry.jsonl
- manifest.jsonl
- structure.md

Новая реальная концепция создаётся в `Concepts/<concept_slug>/` только после запроса пользователя.
