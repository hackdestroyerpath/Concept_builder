# Issue template

[Назад к README](../../README.md)

## Назначение

Шаблон набора файлов для complex issue.

## Состав

- state.json
- reason.md
- requirements.md
- plan.md
- solution.md
- contract.md
- output_report.md

Рабочий issue создаётся не здесь, а в `Issues/active/<issue_id>/` или внутри concept issue folder.
